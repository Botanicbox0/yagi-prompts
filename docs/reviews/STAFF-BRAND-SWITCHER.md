# 운영자 브랜드 전환 검증

2026-09-23 · `codex/staff-brand-switcher`

## 권한

서버에서 확인한 회사 이메일(`email_confirmed_at`, 같은 사용자 ID, 정확한
`yagiworkshop.xyz` 도메인) 또는 기존 DB 관리자 권한으로 모든 브랜드를 열람한다.
고객 소유권이나 멤버십은 만들지 않는다. 고객 승인·생성·할당 차감 권한은 그대로다.
기존 브랜드 멤버십이 있으면 그 브랜드에서는 기존 역할을 유지한다.

## 확인 결과

- `npx tsc --noEmit`: 통과.
- `npx vitest run`: 145개 파일 / 1,622개 테스트 통과.
- `npm run build:local`, `npm run start:local`: 통과.
- `npm run sweep:anon`: **SWEEP PASSED — 637/637**.
- 로컬 관리자 픽스처(멤버십 없음): 기존 브랜드, 다른 브랜드, 빈 브랜드 선택 가능.
- 브랜드 변경 시 URL과 캠페인·사이드바가 함께 변경됨. 미공개 캠페인에는 공개 전 표시.
- 390px 모바일: 메뉴 열림, 가로 넘침 없음, 고객 승인·업로드 폼 없음.
- 실제 언어 선택 컨트롤로 영문 전환 확인. 빈 브랜드·팀·설정·스튜디오 열람 확인.
- 브랜드 운영 도메인은 `/admin`을 차단하므로 관리자 링크는 `admin.twings.app`으로
  연결한다. 로컬·프리뷰는 상대 경로를 유지하며 실제 페이지 렌더링 회귀 테스트로 검증했다.
- 도메인 인증 경로, 미확인 이메일·다른 사용자 세션·위조 도메인·외부 고객 차단은
  실제 서비스/라우트와 PGlite를 쓰는 테스트로 검증했다. 로컬 픽스처는 OAuth 세션이 없다.

신규 마이그레이션과 환경변수는 없다. 실제 고객 데이터·초대 메일은 변경하지 않는다.
개발 서버 재컴파일 중 JSON 오류가 발생했으나 서버 재시작 및 저장소 밖으로 로그를
이동한 뒤 재현되지 않았고 배포 빌드도 통과했다. 개발 서버 로그는 저장소 밖에 둔다.
