# 브랜드 로그인 화면

2026-09-22. `D:\AI\projects\yagi-workshop`의 로그인 소스를 참고해, 서비스 소개와 로그인 / 콘텐츠 쇼케이스의 두 영역을 TWINGS에 맞게 구성했다. 참고 저장소는 변경하지 않았다.

## 범위와 표현

- `brand.twings.app`의 로그인과 브랜드 경로로 돌아가는 로컬·프리뷰 로그인에 적용한다. 소비자·관리자 로그인은 기존의 간결한 화면을 유지한다.
- 브랜드는 목표·예산·참고 자료를 의뢰하고, 스튜디오가 제작과 크리에이터 운영을 맡는다. 브랜드 공간에서는 콘텐츠를 검토·승인하고 게시물과 측정 출처·시점이 있는 최신 성과를 확인한다. 크리에이터 직접 모집이나 자동 수집·성과 보장은 약속하지 않는다.
- 공개 중인 TWINGS 캠페인 이미지 세 장을 `콘텐츠 예시`로 표시한다. 고객명·새 실적 숫자·가상의 대시보드는 추가하지 않는다. 브랜드 도메인에서는 기존 공개 사이트의 이미지 주소를 사용해 호스트의 접근 허용 범위를 넓히지 않는다.
- 한글 Pretendard Variable, 영문 라이선스 Helvetica Neue와 기존 TWINGS 로고 / `by yagi workshop`을 사용한다. 참고 사이트의 다른 서체·색상은 가져오지 않는다.
- 모바일에서는 소개와 로그인을 먼저 배치하고 쇼케이스를 이어서 보여준다. 문안은 `messages/ko.ts`, `messages/en.ts`에 있다.

## 동작과 인증

- 로그인 링크·안내·약관 동의·첫 이미지는 서버 HTML에 있다. 쇼케이스의 JavaScript가 실행되지 않아도 OAuth 진입은 가능하다.
- Google / 카카오 순서와 제공사 브랜드 색상, 안전한 `next`, 초대 링크, 기존 법무 문안을 유지한다. OAuth 세션이나 제공사 설정, 권한·가입 정책을 바꾸지 않는다.
- 지역별 기본 언어와 수동 KO/EN 선택은 선행 PR #13 / `docs/BRAND-LOCALE.md`를 따른다.
- 쇼케이스는 6.5초 간격으로 전환한다. 마우스를 올리거나 탭이 숨겨지면 일시 정지한다. 수동 선택·키보드 진입은 자동 전환을 멈추며 명시적으로 다시 시작할 수 있다. 동작 줄이기 설정에서는 자동으로 시작하지 않고 이미지 전환 애니메이션도 제거한다.
- 이미지 로드 실패는 번역된 대체 안내로 표시한다. 이미지는 로그인과 독립적이다.

- 새 브랜드 진입 회귀 테스트: 적용 호스트, 브랜드 초대 복귀주소, OAuth 오류·약관·제공사 링크, 소비자/관리자/위험한 next 제외, 영어·서버 HTML. 구현 전 3개 실패를 확인했다.
- 브라우저에서 1440px 데스크톱, 390px 및 320px 모바일, 한국어·영어, 오류 표시, 수동 이미지 선택, 자동 전환 정지·재시작을 확인한다. 증거는 `evidence/brand-auth/`.
- 회귀 시나리오: 새 화면에서 자동 전환이 시작된 뒤 정지 버튼을 처음 클릭한다. 버튼이 시작으로 바뀌어야 한다. 처음 구현에서는 포커스 정지 후 클릭 토글이 재시작시켰고, 키보드 `:focus-visible` 진입만 포커스로 정지하도록 수정했다. 이 이벤트 순서는 실제 브라우저로 검증했다. 현재 Vitest는 DOM 이벤트 환경이 없으므로 모의 이벤트 테스트를 실제 브라우저 검증으로 대신하지 않는다.
