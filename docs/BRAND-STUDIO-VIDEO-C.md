## 1. 목표와 하지 않을 것

### 목표
1. **좌측 조작 패널 + 우측 결과·가이드 2단 작업대**: 기존 하단 플로팅 프롬프트 바 + 별도 서랍으로 흩어져 있던 비디오 스튜디오(`/brand/studio/video`)를 영상 제작에 맞는 **왼쪽 고정 조작 패널(데스크톱 368px) + 오른쪽 결과(`기록`) · `사용 방법`(3단계 시각 카드) 영역**으로 재편한다.
2. **상단 2탭 (`영상 만들기` / `영상 편집`) 일원화**:
   - **`영상 만들기`**: `문장·참조로 만들기`(시작/끝 프레임 또는 참조 이미지 최대 9장 + 프롬프트)와 `설계도로 재현`(참고 영상을 샷 표로 읽어 제품·인물·장소만 바꿔 새로 촬영)을 한 패널 안에서 전환한다.
   - **`영상 편집` (Seedance 기반)**: 4~30초 영상을 올리거나 에셋에서 고른 뒤 **구간·화면 영역 고르기 모달**(3분할 크롭 상자 8핸들 + 필름스트립 타임라인 구간 핸들 + `건너뛰기` / `적용`)을 거쳐 참조 이미지 최대 9장과 편집 지시문으로 원본 길이·구도를 유지한 편집본을 만든다.
3. **`@` 에셋 부르기와 사운드·모델·규격 제어**: 프롬프트 입력창에서 `@`를 치거나 `@ 에셋` 버튼을 누르면 보관된 이미지·영상 에셋을 즉시 참조 목록에 붙이고 `@이미지 1` / `@영상 1` 표기를 본문에 넣는다. 사운드(`소리 켜기` / `음악 없이` / `소리 끄기`), 길이(`4~15초`), 비율(`9:16`·`3:4`·`1:1`·`4:3`·`16:9`·`21:9`), 해상도(`480p 시안`·`720p`·`1080p`), 필요 크레딧을 한눈에 보여 준다.
4. **제작 의뢰 분리**: 기존 `?view=request` 화면은 묶음 E의 3단계 프로젝트 의뢰(`/brand/projects/new`)로 연결·리다이렉트하고, `commission-tracks.ts`가 참조하는 사전 키(`studioVideo.requests.tracks`)는 호환 유지한다.
5. **규모 확장 위험 선제 해결 (`R-03` · `R-06` · `R-08`)**:
   - `R-03`: 허용량이 닫힌 조직(`capKrw <= 0`)의 무료 Gemini 호출(`prompt.enhance`, `film.analyze`)을 차단하고 분당 호출 상한을 둔다.
   - `R-06`: 계정 경로 워커(`scripts/brand-studio-lane-worker.mjs`)와 서버 `laneLoad`(`lib/brand-studio/lanes.ts`)가 작업 행 수가 아닌 **실제 출력 슬롯 수(`outputs.length`)** 기준으로 동시 실행 한도를 세어 제공사 동시 20개 한도를 넘지 않게 막고, 워커 응답이 끊긴 `running` 작업을 정리한다.
   - `R-08`: `loadStudioState` 초기 조회 시 이미지 계열(`image`, `region_edit`) 최근 60건과 영상 계열(`video`, `video_remix`, `video_final`) 최근 60건을 분리 조회해 이미지 다량 생성이 비디오 기록을 밀어내지 않게 한다.

### 하지 않을 것 (Non-Goals)
- **모션 컨트롤 탭 미노출 (2026-11-12 대표 확정)**: 초기 개편(묶음 C)은 `'영상 만들기'` + `'영상 편집'` 2탭만 오픈하고 모션 컨트롤은 제외한다.
- **영상 편집 4.0~30.0초 엄격 검증 및 최소 폭 4.0초 고정 (2026-11-12 대표 확정)**: Seedance 2.5 최소·최대 조건에 맞춰 `4.0초 이상 ~ 30.0초 이하` 클립만 업로드·선택할 수 있도록 브라우저 업로드 전 메타데이터 검증 및 에셋 선택 검증을 거치며, 구간 슬라이더 핸들은 최소 폭 `4.0초`로 고정한다.
- **제공사 미지원 하위 도구 미노출**: Sunra `seedance-2.5` 카탈로그에서 지원하지 않는 클라우드 영상 연장(`Extend Video`), `SDR to HDR`, `FPS Boost` 가짜 메뉴는 넣지 않는다. 실제로 동작하는 `영상 편집`, `설계도로 재현`, `480p 시안 → 1080p로 완성`, `캠페인으로 보내기`만 노출한다(로컬 `SeedVR2` 업스케일 워커 연동은 S4 별도 단계).
- **B2B 본인 얼굴 게이트 없음**: 대표 결정(2026-11-11)에 따라 B2B 비디오 스튜디오에는 본인 얼굴 확인 체크박스를 두지 않는다. 제공사 안전 검수와 차단 시 1회 문구 재시도(`lib/brand-studio/block-retry.ts`)는 그대로 유지한다.
- **모픽 샌드박스 및 원화·엔진 표기 금지**: 모픽·`generative_media` 차단 조직 `404` 하드라인을 유지하고, 화면에는 원화(`₩`)·달러(`$`) 대신 크레딧(`1 크레딧 = 10원`)만 표시하며 내부 공급처 이름을 노출하지 않는다.

## 3. 데이터 모델과 계약

새 DB 마이그레이션 없이 기존 `brand_studio_jobs` · `brand_studio_assets` · `brand_studio_outputs` 계약을 그대로 사용한다.

1. **`video` 작업 (`kind: 'video'`)**:
   - 시작/끝 프레임(`references` 내 `frame: 'start' | 'end'`) 또는 다중 참조 이미지(최대 9장) + 프롬프트(`@이미지 1` 등 멘션 포함) + `audio`(`native` | `ambient` | `silent`) + `seconds`(`4..15`) + `aspect` + `resolution`(`draft` | `720p` | `1080p`).
2. **`video_remix` 작업 (`kind: 'video_remix'`)**:
   - `영상 편집` 탭: `method: 'edit'`, 편집 대상 영상 에셋 1개(`4~30초`) + 선택 참조 이미지 최대 9장 + 바꿀 내용(`change`/`prompt`) + `resolution`(`draft` | `720p` | `1080p`). 출력 길이는 원본(또는 모달에서 자른 클립) 길이를 그대로 따른다.
   - `영상 만들기 > 설계도로 재현`: `method: 'blueprint'`(또는 `reference`), `film.analyze`(`depth: 'blueprint'`)로 읽은 샷 표(`shots`)와 바꿀 제품·인물·장소 슬롯을 조합해 생성한다.
3. **매체별 작업 기록 분리 조회 (`lib/brand-studio/repo.ts`)**:
   - `jobsOfByMedium(sql, organizationId, medium, limit = 60)` 추가: `image` 계열과 `video` 계열을 각각 최신 60건씩 읽어 합산 반환한다.
4. **슬롯 기준 레인 부하 계산 (`lib/brand-studio/lanes.ts`, `scripts/brand-studio-lane-worker.mjs`)**:
   - `laneLoad`: 열린 작업의 `brand_studio_outputs` 개수(`coalesce(count(o.id), 1)`) 합산으로 슬롯 사용량을 계산한다.
   - `brand-studio-lane-worker.mjs`: `activeSlots` 합산으로 `free = MAX - activeSlots`만큼만 `claim`하고, 한 작업이 요청 슬롯을 넘기지 않도록 제한한다.

## 4. 실패했을 때의 동작

- **클립 길이 부적합 (4.0~30.0초)**: `영상 편집`에 4.0초 미만, 30.0초 초과, 또는 길이를 읽을 수 없는 영상을 올리거나 고르면 업로드·첨부 단계에서 즉시 차단하고 사유를 알리며, 구간 슬라이더 핸들은 어떤 방향으로 드래그해도 최소 간격 `4.0초`가 유지된다.
- **브라우저 클립 자르기 미지원 코덱**: 브라우저에서 MP4 녹화 코덱을 지원하지 않거나 변환이 실패하면 원본 에셋을 손상시키지 않고 안내 문구와 함께 원본 그대로 쓰기(`건너뛰기`)로 안전하게 폴백한다.
- **`@` 참조 누락**: 본문에 `@이미지 3`을 적었는데 참조 슬롯에 이미지가 2장뿐이면 서버 호출 전에 `findMissingReferences`가 잡아 어떤 번호가 빠졌는지 바로 알린다.
- **무료 분석·보정 과호출 / 허용량 0 (`R-03`)**: 월 허용량이 0(`capKrw <= 0`)이면 `allowance_closed`, 분당 제한 초과 시 `too_many_running`을 돌려보내고 화면에 차분한 상태 안내를 띄운다.
- **제공사 안전 검수 차단**: 기존 `planBlockRetry`가 문장을 1회 자동 순화해 재시도하며, 2회 연속 거절되면 예약 크레딧을 `0`으로 즉시 환불한다.

## 5. 측정 지표와 되돌리는 방법

- **측정 지표**:
  - `영상 만들기` 대 `영상 편집` 실행 비율 및 `480p 시안 → 1080p 완성` 전환율
  - `구간·화면 영역 고르기` 모달의 `적용` 대 `건너뛰기` 비율
  - `sunra_mcp` 동시 활성 슬롯 최댓값(`<= STUDIO_LANE_MAX`) 및 무료 보정/분석 분당 호출 수
- **되돌리는 방법**:
  - DB 스키마 변경이 없는 순수 애플리케이션 PR이므로, 문제 발생 시 해당 병합 커밋 1개를 `git revert`하면 즉시 이전 비디오 스튜디오 화면과 쿼리로 복원된다.
