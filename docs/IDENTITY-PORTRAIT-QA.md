# 내 얼굴 기준 사진 — 검증 기록

2026-09-22 · `codex/identity-portrait` · 클라우드 미적용

## 실제 모델 연결과 화면 검증의 구분

- 실제 OpenAI Sunburst 편집 API: 사람을 포함하지 않은 단색 입력, 대표 프롬프트 원문, `quality=max`, 1344×2016. HTTP 200, 출력 크기 일치, 약 69초. 개인 얼굴 보존 품질을 검증했다는 뜻은 아니다.
- 화면 검증: 로컬 일반 사용자와 `LOCAL QA FIXTURE`라고 표시된 합성 도형 입력·응답을 사용했다. 실제 인물 사진을 테스트 목적으로 제공사에 보내지 않았다.
- 얼굴 일치 여부: 완성된 사진과 원본을 사용자가 비교해 선택한다. 자동 유사도 점수나 본인 인증 성공으로 표시하지 않는다.

## 브라우저에서 확인한 동작

| 단계 | 관찰 결과 |
| --- | --- |
| 첫 진입 | 무료 2회, 본인 사진 동의 전 생성 버튼 비활성 |
| 첫 생성 | 진행 상태 후 원본·완성 사진과 “내 얼굴처럼 나왔나요?” 표시, 남은 1회 |
| 첫 선택 | “네, 이 얼굴로 사용할게요” 후 “다음 작품에 사용할 얼굴” 표시 |
| 다시 만들기 | 다른 사진 선택으로 복귀, 새로 생성하는 동안 기존 선택 유지 |
| 두 번째 완료 | 남은 0회, 생성 버튼 없음, 두 후보 모두 확인 가능 |
| 두 번째 선택 | 새 후보 선택 및 새로고침 후 저장 확인 |
| 모바일 390×844 | 원본·결과 비교와 선택 가능, 가로 넘침 없음 |
| 업로드 예시 | 대표 지정 사진 4장, 좋은 예시 2장·가림 1장·회전 1장 표시 |

브라우저 스크린샷은 작업 대화에 남겼다. 생성 결과 스크린샷 속 도형은 UI 검증용이며 실제 Sunburst 출력 예시가 아니다. 업로드 안내의 예시 사진은 실제로 제공된 네 장을 사용하고, 생성 입력에는 포함하지 않는다.

개발 서버에서는 `http://localhost:4786`을 사용했다. `127.0.0.1`과 Next 개발 서버의 요청 기준 주소가 달라 POST가 403으로 거절되는 것을 확인했고, 동일 주소로 접속해 해결했다. CSRF 검사를 완화하지 않았다.
