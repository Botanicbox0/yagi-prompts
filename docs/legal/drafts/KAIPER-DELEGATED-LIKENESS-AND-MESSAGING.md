# 캠페인 대리 제작·대화 처리 변경안

**검토용 초안 — 미시행.** 2026-10-16 대표 요청에 따라 준비했다. `lib/legal/documents.ts`를 대체하지 않는다. 금액·기간·법적 처리근거·제공사 허용 범위와 대표 검토가 확정되기 전에는 서비스 동의 문구로 사용하지 않는다.

## 1. 기본 방식과 대리 제작의 구분

기본 방식은 참여자 본인이 TWINGS 계정에 가입하고 자신의 사진을 등록해 제작하는 것이다. 대리 제작은 참여자가 특정 브랜드 담당자에게 특정 캠페인의 제작 업무만 맡기는 별도 권한이다. 브랜드 계약, 캠페인 선정, 브랜드가 보유한 사진, 과거 동의는 새 캠페인 대리 제작의 승인을 대신하지 않는다.

대리 제작에서도 인물 자산 소유자는 참여자다. 담당자 계정에 타인의 얼굴을 본인 얼굴로 등록하지 않는다. 제공사 검수와 필요한 본인 인증을 그대로 적용한다. **사진을 먼저 모아두고 나중에 동의를 받는 흐름은 열지 않는다.**

## 2. 인플루언서 확인 화면의 초안

> [브랜드명]의 [담당자 표시명]이 [캠페인명]에서 사용할 콘텐츠를 대신 만들려고 합니다. 아래 범위를 확인해 주세요. 이 승인은 다른 캠페인, 다른 브랜드, AI 학습 또는 별도 광고 활용을 포함하지 않습니다.

서명 전에 반드시 확정하여 표시할 항목:

| 항목 | 필수 내용 |
| --- | --- |
| 요청자 | 브랜드 법인/조직, 승인 대상 담당자 계정 |
| 본인 | 로그인 계정과 본인 확인 결과; 브랜드가 입력한 이름만으로 대체 불가 |
| 대상 | 캠페인, 고정 포맷 버전, 본인이 확인한 사진/인물 자산 |
| 행위 | 사진 등록 대행, 생성 실행, 결과 확인 중 허용 항목을 각각 표시 |
| 범위 | 목적, 채널, 지역, 제작 기간, 생성 허용량, 결과 이용 기간 |
| 보상 | 해당 참여 조건의 확정 버전·통화·금액·지급 주체·조건; 별도 변경 동의 |
| 공유 | 브랜드가 볼 수 있는 결과물/진행 상태; 원본 얼굴 다운로드는 별도 승인 없이는 불가 |
| 처리 | 처리 항목·목적·보관 기간·위탁/국외이전·동의 거부와 철회 방법 |

선택 항목 예시(기본 미선택):

- ‘위 담당자가 이 캠페인에서 지정된 사진을 등록하고, 지정된 포맷의 콘텐츠를 제작하도록 승인합니다.’
- ‘위에 표시된 개인정보 처리 항목·목적·보관 기간을 확인했습니다.’

참여 동의, 개인정보 수집·이용, 제3자 제공/국외이전이 필요한 경우의 고지·동의, 향후 캠페인 추천/연락 동의는 각각 구분해 설계한다. 의무 및 법적 근거는 법무 검토로 확정한다. 향후 추천에 동의하지 않아도 현재 캠페인 참여와 본인 제작이 불리해지지 않도록 한다.

## 3. 이용약관 §5 변경 제안

> 이용자는 원칙적으로 자신의 얼굴만 등록하여 제작할 수 있습니다. 회사가 별도로 제공하는 캠페인 대리 제작 기능에서는 얼굴의 당사자가 본인 계정에서 특정 브랜드 담당자, 캠페인, 포맷, 사진과 사용 기간을 확인하고 승인한 경우에만 해당 담당자가 승인 범위의 등록·제작을 수행할 수 있습니다. 당사자의 승인은 인물 자산의 소유권이나 포괄적인 사용 권한을 브랜드에 이전하지 않습니다. 회사 및 제공사의 검수와 필요한 본인 인증 절차는 대리 제작에도 적용됩니다.

> 승인 대상 담당자, 포맷, 사진, 용도 또는 기간이 달라지면 새 승인을 받아야 합니다. 당사자는 계정에서 대리 제작 승인을 철회할 수 있으며 철회가 기록된 이후의 새 등록·제작 요청은 허용되지 않습니다. 이미 처리 중이거나 완료된 제작물의 처리와 이용 중단 범위는 승인 화면에 고지한 조건과 관련 법령에 따라 별도로 처리합니다.

**검토 필요:** 미성년자 참여와 대리 승인 방법, 이미 제공사에 전달된 작업의 취소 가능성, 완료 콘텐츠의 광고 중단·회수 요청, 증빙 보존 기간. 확정하지 않은 항목은 UI에서 허용하지 않는다.

## 4. 개인정보처리방침 추가안

| 처리 | 항목 | 목적 | 보관/전송 조건 |
| --- | --- | --- | --- |
| 대리 제작 승인 | 당사자·담당자 계정, 범위·버전·동의/철회 시각, 인물 자산 식별자 | 승인 범위 확인, 분쟁 대응 | 기간과 처리근거 법무 확정 필요 |
| 캠페인 대화 | 메시지, 첨부, 참여 관계, 읽음/변경 이력 | 캠페인 협업·납품·지원 | 역할별 접근 및 캠페인 종료 후 보관 기간 확정 필요 |
| 위험 검토 | 분석 대상 메시지, 분류 근거, 모델/규칙 버전, 사람의 검토 결과 | 외부 입금 유도 등 운영상 위험의 검토 | 원문 별도 복제 최소화, 모델 학습 재사용 없음, 접근 기록 |
| Slack 알림 | 사건 식별자, 고정된 유형, 관리자 링크 | 운영자에게 검토할 항목 알림 | 대화·이름·얼굴·계좌·결제 키를 전송하지 않음 |

위탁 처리와 제3자 제공의 구분, Slack 사용에 따른 처리방침 항목, 국외이전이 발생하는 범위는 실제 구성으로 검토한다. ‘로컬 AI’라는 명칭만으로 법적 근거 또는 고지를 생략하지 않는다.

메시지 화면 안내 초안:

> 이 대화는 캠페인 협업을 위한 비공개 공간입니다. TWINGS는 운영상 위험을 확인하기 위해 대화를 자동 분석하고, 필요한 경우 권한 있는 담당자가 검토할 수 있습니다. 분석 결과만으로 참여 제한이나 지급 중단을 결정하지 않습니다. 계좌번호나 신분증 같은 민감한 자료는 대화에 올리지 말아 주세요.

## 5. 구현·운영 조건

- 승인 상태: draft → awaiting_subject_consent → consent_recorded → studio_review → approved. 만료·철회·정지·거절은 별도 기록.
- 범위 문서 해시와 본문 버전 불변 저장. 본인 인증 시점과 권한 부여 시점 구분.
- 요청 시점과 제공사 발송 직전 권한·유효기간·인물 소유권·검수 상태를 다시 확인.
- 현재 구현 단계에서는 대리 얼굴 업로드·생성 경로를 열지 않는다. 문서 초안만으로 기존 본인 전용 가드를 완화하지 않는다.
- 제공사가 타인 사진의 대리 등록을 허용하지 않으면 본인이 직접 등록하고 제작하는 경로를 유지한다.
- 공개 약관 교체·정책 버전 발행·기존 사용자 재동의·실행 플래그 활성화는 별도 승인/출시 절차로 기록한다.
