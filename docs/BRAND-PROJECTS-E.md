# ‘야기 팀과’ 재설계 — 프로젝트 · 작업물 중심 리뷰 · 알림함 · 3단계 의뢰 · 외주 전용 조직 (묶음 E)

## 1. 목표와 하지 않을 것

- **목표**
  1. **레일 및 공간 분리**: 좌측 레일의 `야기 팀과` 묶음을 **`프로젝트` (`/brand`)**와 통합 **`알림함` (`/brand/rooms`)** 두 개로 단순화하고(`크리에이터`는 캠페인 공간 상단 진입으로 이동), `프로젝트` 진입 시 셀프 스튜디오와 구분되는 전용 프로젝트 공간 헤더·단계 필터·원클릭 룸 진입을 제공한다.
  2. **작업물 중심 프로젝트 룸 (`/brand/rooms/[projectId]`)**: 탭을 **`개요` · `파일`(기획서 / 스토리보드 / 시안 / 최종본) · `대화`** 3개로 재편한다(기존 `?tab=storyboard`·`?tab=review` 주소는 `파일`의 해당 분류로 100% 하위 호환). 의견은 대화창이 아닌 **작업물 위**(영상 시간·구간·프레임 드로잉, 이미지·문서 위치 핀)에 남기고, 모든 작업물 의견·버전 업로드·승인 상태 변경이 **`대화` 탭과 `알림함`에 클릭 가능한 점프 카드로 자동 유입**되게 연결한다.
  3. **Frame.io V4 수준 시안 리뷰 및 공유 보강**: 버전 스택 및 나란히 비교 위에 **재생 배속(`0.5×`~`2×`)**, **`J`/`K`/`L` 셔틀 및 `,`/`.` 1프레임 이동**, **의견 다중 필터(`열림`·`해결됨`·`전체` + 드로잉 포함·작성자 검색)**, **의견 내보내기(`CSV` · `Markdown 체크리스트` · `편집기 타임코드 마커`)**, **공유 링크 권한·만료·암호(IP 해시별 잠금 `R-09`)·원본 다운로드**를 완성한다.
  4. **3단계 의뢰 접수 폼 (`/brand/projects/new`)**: `1. 무엇을 맡기나` → `2. 자료(기획서 파일·텍스트 붙여넣기·참고 링크·브랜드 에셋 선택 + 기획서 기반 2·3단계 자동 채우기)` → `3. 조건(결과물 사양·희망 일정·예산 구간 + ‘아직 모름’·담당자·승인권자)` 구성과 브라우저 자동 임시 저장을 도입한다. 고객 화면과 DB `objective`에서 내부 컴파일러 용어(`[TRACK: ...]`, `OLED Color Look` 등)를 완전히 제거하고, 관리자 화면(`/admin/brand-workspace`, `/admin/brand-workspace/[id]`, `/admin/brand-rooms`)에 새 필드를 구조화해 표시한다.
  5. **비구독 프로젝트 전용(외주) 고객 지원**: `lib/brands/features.ts`의 “기본 개방 + 조직별 차단 목록” 원칙을 따라 **`self_studio`** 차단 키와 **`project_only`** 플랜 구분을 추가한다. 모픽(`Morphic`·`모픽`·샌드박스 ID) 및 `generative_media` 차단 조직의 기존 `sidebar`·`404` 하드라인은 1비트도 약화하지 않고, 외주 전용 조직만 셀프 스튜디오(`이미지/비디오 스튜디오`)를 닫고 `프로젝트`·`알림함`·`에셋` 공간을 열 수 있게 한다.

## 2. 방향 조정 기록

- **원래 요청**: 레일 `야기 팀과`를 `프로젝트` 하나로 줄이고 `메시지`·`리뷰` 메뉴를 없앤 뒤 모든 프로젝트의 새 의견·승인 요청·새 버전을 모은 `알림함` 하나로 대신할 것; 비구독 외주 고객이 `프로젝트` 공간만 쓸 수 있게 설계할 것.
- **구체화한 방향**:
  1. 레일 `야기 팀과` 묶음에 **`프로젝트`(`/brand`)**와 미확인 배지가 붙는 **`알림함`(`/brand/rooms`)** 두 항목만 둔다(`크리에이터`는 캠페인 공간 상단 도구 모음으로 이동). 알림함이 레일 한 칸을 가져야 어느 화면에서든 새 시안·승인 요청·의견 도착을 즉시 확인하고 한 번에 이동할 수 있다.
  2. 비구독 외주 고객 분리는 기존 `generative_media` 가드를 푸는 대신 **`self_studio` 기능 키**를 새로 추가해 처리한다.
- **이유**: 기존 운영 DB와 하드라인 테스트(`tests/brand-rooms/sandbox.test.ts`, `tests/brand-studio/shell/navigation-modes.test.tsx`)에서 `generative_media` 차단은 모픽 등 경쟁·샌드박스 조직에 대해 스튜디오와 룸을 모두 닫고 구형 사이드바를 유지하는 안전장치로 고정되어 있다. `self_studio`를 별도 키로 두면 기존 샌드박스 불변 조건을 100% 보존하면서 외주 전용 조직에만 깔끔하게 프로젝트 룸을 열 수 있다.

## 4. 데이터 모델 및 마이그레이션 (`0085` · `0160`)

기존 테이블을 그대로 살리고 하위 호환되는 선택 컬럼·인덱스만 추가한다 (`isSchemaGap` 허용으로 마이그레이션 적용 전후 무중단 동작).

1. **`brand_projects.intake_brief jsonb`** (`0085_core_brand_projects_intake_and_rooms.sql`)
   - 3단계 의뢰 폼의 구조화 데이터를 저장한다:
     - `version`: `1`
     - `track`: `'template_build' | 'creator_campaign' | 'studio_film' | 'other'`
     - `summary`: 한 줄 목표
     - `briefText`: 붙여넣은 기획 내용
     - `briefAttachmentIds` / `studioAssetIds`: 첨부 기획서 및 선택한 브랜드 에셋 ID 목록
     - `deliverables`: `{ kind, duration, aspectRatios, quantity, channels }`
     - `schedule`: `{ startsOn, dueOn }`
     - `budgetBand`: `'under_300' | '300_500' | '500_1000' | '1000_3000' | 'over_3000' | 'undecided'` (상수 테이블 분리, 대표 Q6 확정 시 즉시 반영)
     - `contact`: `{ name, channel, value, approver }`
2. **`brand_room_shares.unlock_buckets jsonb not null default '{}'::jsonb`** + **`idx_brand_room_share_visits_cleanup`**
   - 암호 실패 횟수를 링크 전체가 아닌 `ipHash16 -> { count, windowAt }` 단위로 기록해 제3자 오입력으로 정당한 고객사 링크가 잠기는 DoS(`R-09`)를 차단한다.
   - `brand_room_share_visits(share_id, hour)` 인덱스를 추가해 조회수 집계 시 테이블 스캔을 제거한다.
3. **`brand_room_messages` 이벤트 확장 (`review_commented`)**
   - DB 제약(`event ~ '^[a-z_]{1,40}$'`, `ref_key ~ '^(storyboard|review):...'`) 변경 없이 시안 의견 등록(브랜드 멤버·공유 링크 게스트·야기 팀) 시 `review_commented` 이벤트를 기록하고, `refViews`에서 해당 코멘트의 `atMs`·`endMs`·드로잉/핀 여부·본문 요약을 함께 조합해 `대화` 탭과 `알림함`에서 즉시 해당 프레임으로 점프하게 한다.
4. **권한 부여 (`0160_glue_brand_projects_intake_and_rooms.sql`)**
   - `grant update(intake_brief) on brand_projects to service_role;` (기존 `brand_projects` 컬럼 단위 UPDATE 최소 권한 원칙 준수).

## 6. 실패했을 때의 동작 · 측정 지표 · 되돌리는 방법

- **실패 동작**:
  - 기획서 자동 채우기 파서가 날짜·예산·비율을 찾지 못하면 빈칸을 억지로 추측하지 않고 찾은 항목만 채우며 고객이 직접 고칠 수 있게 안내한다.
  - 의뢰 작성 중 네트워크·세션이 끊겨도 `localStorage` 자동 저장본이 복구된다.
  - R2 직접 업로드 미설정 환경(로컬 개발 등)에서는 자동으로 기존 서명/로컬 업로드 경로로 폴백한다.
  - 작업물 의견의 `대화` 이벤트 기록이 실패해도(savepoint 롤백) 원본 의견 저장 자체는 절대 실패하지 않는다.
- **측정할 숫자**:
  - 의뢰 폼 단계별 이탈률 및 기획서 자동 채우기 사용 비율.
  - 시안 업로드 후 고객 첫 의견·승인까지 걸리는 시간( 중앙값 ).
  - `/api/brand-rooms/*` 탭당 분당 호출 수(`R-05` 적용 전후 비교).
- **되돌리는 방법**:
  - 코드 PR `git revert` 시 기존 레일·탭·의뢰 마법사로 즉시 복구된다(`0085`에서 추가한 `intake_brief`, `unlock_buckets`는 nullable/default 컬럼이라 구버전 코드와 충돌하지 않는다).
