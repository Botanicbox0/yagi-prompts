## Gotchas learned

- Real Supabase `sb-*` cookies on localhost override the dev identity fixture → 500/404. Clear cookies.
- `sleep N` chains are blocked in the Claude tool; poll with `timeout N tail -f /dev/null` loops.
- A `next dev` run overwrites `.next`; rebuild with `build:local` before `start:local` + sweep.
- Python heredocs with Korean: set `PYTHONIOENCODING=utf-8`; write scripts to a file when quotes get messy.
- Playwright: `playwright-core` + `C:/Users/User/AppData/Local/ms-playwright/chromium-1234/chrome-win64/chrome.exe`; hide `nextjs-portal`; pass `--autoplay-policy=no-user-gesture-required` to test autoplay.
- HEVC source videos do not play in browsers; transcode to H.264 (`ffmpeg … -c:v libx264 -crf 24 -movflags +faststart`).
- Dictionary test rejects identical ko/en values (e.g. "300+"); localise ("300건+").
