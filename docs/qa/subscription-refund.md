# 월 구독 환불 안내 공개

2026-10-14 대표 요청. 월 구독 설명을 결제 개방 전에도 환불정책과 약관에서 볼 수 있게 한다. 문구 검토는 Opus 4.6, 코드·정합성 검토는 Opus 5.5로 분리한다.

## 범위와 공개 상태

- 준비 중에도 `/ko/legal/refund`, `/en/legal/refund`에 월 구독 해지·환불을 먼저 표시한다. 단건 구매 기준은 별도 영역에 유지한다.
- 약관의 결제 조항도 두 방식으로 구분한다. 월 구독이 준비 중이라는 안내를 표시하며 실제 신청·결제를 받는다고 말하지 않는다.
- 실제 개인정보 처리 범위는 현재 승인 상태를 따른다. 미승인 Premium 처리 조항을 이미 시행 중이라고 바꾸지 않는다.
- 문안 버전은 `creator-subscription-2026-10-14-v2`. 동의·증빙 해시는 안내문 없는 승인본에서 계산한다. 페이지 공개만으로 승인 기록이나 판매 개방을 만들지 않는다.

## 실제 코드와 맞춘 내용

1. 해지: 다음 자동결제 중단, 이미 결제한 기간까지 이용. 진행 중 결제는 결과 확인 후 처리한다.
2. 계정 전액 환불: 현재 미만료 기간의 영상 사용량·예약량이 모두 0이고 다른 결제가 미확정 상태가 아니어야 한다. 접수된 환불 처리 중에는 제작·자동결제가 중단된다. 결제사 취소 확인 후 완료한다.
3. 이용 후/지난 기간/서비스 문제: 고객센터에서 확인한다. 임의의 비례 환불식, 별도 위약금, 첫 이용 후 일괄 거절, 월 구독에 단건 7일 제한을 만들지 않는다.
4. 생성 실패: 해당 영상의 제작량을 복구한다. 월 요금 전체의 자동 환불로 설명하지 않는다.
5. Premium GPT 검토 횟수만으로 전액 환불 조건을 추가 제한하지 않는다. 현재 자동 환불은 영상 사용 장부를 확인한다.
6. 법정 권리: 미제공 부분과 표시·계약 불일치에 따른 권리를 보존한다. 법정 청약철회 환급은 요청일부터 3영업일 기준이며, 회사의 확인일로 다시 시작하지 않는다.

근거: [전자상거래법 제17조 제3항](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031805925), [제18조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022341921). 실제 청약철회 제한은 제17조 제2항·제6항의 요건도 충족해야 한다.

## 운영 검증은 별도

실제 PG 환불·장기 refund_pending 처리·이미 사용한 기간의 고객센터 환불은 출시 전 운영 검증 대상이다. 부분 환불의 계산·이용 권한·장부 조정이 자동화됐다고 말하지 않는다. 실제 계약·키·Worker와 정확한 새 문안 증빙이 갖춰진 후에만 신청을 연다.

검증 결과·정확한 커밋·프리뷰·Production 확인은 PR에 기록한다. 실제 결제·환불·클라우드 SQL·메일 발송·서버 이관은 이 변경에서 수행하지 않는다.
