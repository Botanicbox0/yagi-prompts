# 개인 쪽 아이덴티티 2차 적용 (2026-11-03)

대표 방향(2026-10-30): 브랜드 쪽 디자인 시스템을 보고 "개인 TWINGS도 이런 식으로 보여질 수 있으면 훨씬 더 멋있을 것 같다".
1차(PR #134·#135·#141, 2026-10-31)가 토큰·서체·카드·영상 행을 옮겼다. 이 문서는 그 뒤 main(`ac914d81`)에 남아 있던 차이와 이번에 고친 것을 적는다.

## 실측 방법

- 운영(twings.app)과 로컬 프로덕션 빌드(`npm run build:local`)에서 홈, `/ko/video`, `/ko/image`, 템플릿 페이지, `/ko/pricing`을 1440폭과 375폭으로 전체 캡처했다.
- 1440폭에서 화면에 보이는 모든 요소의 계산된 색, 서체, 모서리를 모아 `docs/design/IDENTITY.md`와 비교했다.
- 템플릿 페이지는 로컬 스냅샷의 첫 영상 템플릿(`/ko/t/neon-alley-dolly`), 운영은 `/ko/t/aquarium-goldfish`다.

## 고치지 않은 것과 이유

- **푸터(검정)**: 브랜드 쪽과 함께 쓰는 마감이고 브랜드 랜딩에서도 그대로다. 푸터의 모노 글자(저작권, 이메일, 사업자 정보)와 다크 섹션 링크 블루 `#4C6FFF`(옛 accent의 다크 버전)도 두 쪽 공통이라 따로 다룬다.
- **템플릿 사진·영상과 글자 포스터**: 템플릿 고유의 미디어라 손대지 않았다.
- **FAQ 블록 폭**: FAQ는 `.band`(1000px 열)라 1920폭에서 개인 쪽 전체 폭 열과 왼쪽 선이 어긋난다. 브랜드·FAQ 페이지와 함께 쓰는 블록이라 이번 범위에서 뺐다.

## 제안 (대표 확인 필요)

- **히어로 증거 사진**: 지금 운영의 "내 셀카"는 분홍 꽃과 분홍 메이크업 컷이다. IDENTITY §2는 분홍 메이크업을 쓰지 않고 따뜻한 사진을 화면당 하나로 둔다. 히어로는 우리가 고르는 자리이니, 거의 맨얼굴의 쿨 화이트 배경 셀카와 블루 월드 장면 한 쌍으로 바꾸는 것을 제안한다. 새 이미지는 IDENTITY §6-4-4대로 후보를 먼저 보여 드린 뒤 `/admin/landing-media`에서 바꾼다. 이번 PR은 이미지를 바꾸지 않았다.
