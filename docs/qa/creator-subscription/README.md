# TWINGS 월 구독 — 운영 준비와 검증

2026-10-10. 구현 준비와 실제 판매 개시는 별개다. 이 문서의 체크를 실행했다고 계약·운영 키·실결제가 자동 승인되지는 않는다.

## 코드에 준비된 것

- 크리에이터 월 24,900원 / Premium 월 49,000원, 부가세 포함. 기존 제공량과 가격을 유지한다.
- 빌링 카드 등록 → 최초 승인 → 월 장부, 다음 달 갱신, 해지, 미사용 기간 환불, 결제 결과가 불명확한 경우 재조회.
- 등록/승인/갱신/환불은 사용자·환경·같은 주문에 묶는다. 승인 금액·통화·주문·잔액 확인 전에 이용 권한을 주지 않는다.
- 빌링키는 별도의 32바이트 키로 AES-256-GCM 암호화한다. 발급 후 저장에 실패한 키는 취소 또는 암호화된 복구 큐로 정리한다.
- 월 영상 사용량 예약·완료·실패 복구는 장부를 잠그는 트랜잭션으로 처리한다. 공개 견적을 개인 잔량으로 쓰지 않는다.
- Premium은 텍스트 800자와 참고 이미지 최대 3장. 작은 색상·조명 변경만 가능하며 원본 프롬프트·얼굴 기준 사진은 GPT에 보내지 않는다.
- 얼굴은 정면, 눈·코·입이 또렷하고 배경이 단순한 본인 사진을 업로드 전에 안내한다. 기존 본인 확인·제공사 검수는 그대로 거친다.
- 요금/랜딩/템플릿/FAQ는 같은 준비 상태를 읽는다. 공개 약관·환불·개인정보 문서는 정확한 문안 승인 후에만 월 구독 내용을 반영한다.

## 운영자가 적용할 항목

1. **계약:** Toss 자동결제 추가 계약, 해당 MID의 사용 권한, 실제 카드 수수료·해외 카드 범위를 확인한다. 이메일 접수나 일반 가맹 승인만으로 자동결제가 가능한 것으로 기록하지 않는다.
2. **클라우드 SQL:** 대표 또는 Director가 아래 순서로 core/glue 파일을 검토·적용한다. 기존 장부나 문의는 삭제하지 않는다.

   - `0042_core_creator_subscriptions.sql` → `0127_glue_creator_subscriptions.sql`
   - `0043_core_premium_edits.sql` → `0128_glue_premium_edits.sql`
   - `0044_core_creator_subscription_release.sql` → `0129_glue_creator_subscription_release.sql`

3. **환경:** 운영자가 Vercel에 빌링 전용 `TOSS_BILLING_CLIENT_KEY`/`TOSS_BILLING_SECRET_KEY`, `TOSS_BILLING_ENCRYPTION_KEY`, `CRON_SECRET`을 직접 넣는다. 일반 위젯 키는 사용할 수 없다. 키가 없으면 판매는 닫힌다. 암호화 키를 잃으면 기존 카드 갱신이 불가능하므로 안전하게 백업한다.
4. **Premium:** `OPENAI_API_KEY`, 지원 모델 `gpt-5.6-sol`, `PREMIUM_EDITING_ENABLED=on`, 명시적인 `PREMIUM_EDIT_REQUESTS_PER_PERIOD`가 필요하다. 공개 신규 계약은 최소 30회가 필요하며 자동 기본값은 없다. 가입한 고객의 한도는 계약에 보관한다.
5. **문안:** 대표/Director가 실제 공개될 한국어·영어 약관·환불·개인정보 문서를 검토한다. `subscriptionTermsDigest()`가 묶는 정확한 내용만 승인한다. 기존 단건 약관에 구독 내용을 덧붙이는 버전은 `legal-projection.ts`에서 확인한다. 개인정보 삭제 요청 시 결제 중단·관련 저장 자산 정리를 함께 수행한다.
6. **작업자:** `ops/creator-subscriptions-worker`의 Cloudflare 스케줄러를 별도로 배포한다. 비밀값은 지원되는 encrypted binding에 직접 등록한다. 15분 주기의 실제 실행을 확인한다. 기본 설정은 off이며 이 저장소를 배포하는 것만으로 Worker가 배포되지는 않는다.
7. **증빙:** 대표/Director가 검증 결과의 SHA-256만 `creator_subscription_launch_evidence`에 기록한다. 관리자 화면은 읽기 전용이다. `passed`를 자동으로 세우거나 버튼으로 자기 승인하는 경로는 없다.
8. **자동 개방:** 정확한 증빙이 모두 갖춰진 후 `CREATOR_SUBSCRIPTION_PUBLIC=on`. Creator는 공통 검증 후 열리고 Premium은 별도 수정 검증까지 통과해야 열린다. paused는 신규 가입을 닫으며 이미 결제한 기간의 장부를 유지한다.

`npm run subscription:readiness`는 현재 환경과 DB를 읽기 전용으로 점검한다. 결제·모델 호출·파일 업로드·승인 기록을 만들지 않고, 비밀값은 boolean으로만 표시한다. exit 2는 준비 미완료다. 운영 Vercel 설정을 로컬에 복사하지 않고 실행 가능한 운영 환경에서 사용한다.

## 승인 증빙의 기준

필수 단계: `contract`, `costs`, `terms`, `registration`, `approval`, `renewal`, `cancellation`, `refund`, `render`, `worker`. Premium 추가: `premium_editing`.

- 모두 `live` 환경, 정확한 플랜/릴리스/약관 버전, 실제 `VERCEL_GIT_COMMIT_SHA`가 일치해야 한다.
- 공통 단계는 `launchConfigurationDigest()`, Premium 수정은 `premiumConfigurationDigest()`에 묶인다. 비밀값은 해시에 넣지 않는다.
- terms는 `subscriptionTermsDigest()`와도 일치해야 한다. 과거 문안 승인으로 새 문안을 열 수 없다.
- worker는 한 시간 안에 실제로 실행됐어야 한다. tick은 이미 승인된 일치 기록의 시각만 갱신하고 새로운 승인 기록을 만들지 않는다.
- 구현 커밋·가격·약관·설정이 바뀌면 신규 신청 검증이 다시 필요하다. 기존 유료 계약 복구와 갱신은 별도로 계속할 수 있다.

## 개인정보 삭제 요청 처리

참고 이미지는 `deleteExpiredEditReferences()`가 처리 완료 후 보관 기한 7일을 넘긴 서버 소유 자산만 정리한다. 모델 호출이나 영상 작업이 진행 중인 자산은 먼저 삭제하지 않는다.

탈퇴 요청은 기존 연락 창구에서 본인 요청을 확인하고 로그인을 중단한 뒤, 자동결제·빌링키·미확정 결제·진행 중 생성 작업을 먼저 정리한다. `lib/premium-editing/privacy.ts`의 `purgePremiumEditDataForAccountDeletion()`은 확인된 관리자와 실제 대상 계정 UUID를 요구하며, 미처리 결제·키·작업이 있으면 삭제를 거절한다. 한 번에 최대 5개의 서버 선택 수정 요청과 검증된 참고 이미지 경로만 지운다. 저장소 삭제 실패 시 요청 행을 유지해 같은 배치를 다시 정리할 수 있다. `complete`는 이 수정 데이터 범위의 완료를 뜻한다.

이 helper는 HTTP 경로·자동 탈퇴·관리자 버튼에 연결하지 않았다. 운영자는 결과의 `remainingRequests`가 0인지 확인하고, 본인 사진·생성 결과·계정은 기존 삭제 절차로 별도 처리한다. 법정 보관 대상 결제·사용 장부를 이 helper로 삭제하지 않는다. 이번 준비 작업에서는 운영 개인정보를 삭제하거나 helper를 운영 DB에서 호출하지 않았다.

## Premium 비용 검토

[GPT-5.6 Sol 공식 가격](https://developers.openai.com/api/docs/models/gpt-5.6-sol)은 현재 100만 토큰당 입력 $4 / 캐시 입력 $0.40 / 출력 $20이다. 최대 출력 600토큰, low-detail 참고 이미지 3장을 사용한다. 입력 총 4,000토큰을 가정하면 요청당 약 39.2원(환율 1,400원), 30회면 약 1,176원이다. 이는 실측 상한이 아닌 보수적 계산 예시이며 과세·가격 변경·실제 이미지 토큰 수는 별도로 확인한다.

이 예시에서 전량 영상 사용 기준 Premium 마진은 기존 9.20%에서 약 6.56%로 낮아진다. 월 가격과 영상 제공량을 바꾸지 않고, 시작 후보 한도를 30회로 검토할 수 있다. 수정 호출 길이·캐시·횟수를 실측 후 확정하고 costs/premium_editing 검증에 남긴다. 공식 프로모션 가격 기한 이후 재검토가 필요하다. 무제한 수정이나 8~10% 마진 보장은 하지 않는다.

## 현재 외부 상태

이번 준비 작업에서는 클라우드 SQL, 운영 키, Worker 배포, 승인 기록을 자동으로 적용하지 않았다. 로컬 확인 범위에서는 GPT 키가 발견되지 않았으며 Vercel 운영 키의 존재는 확인하지 못했다. 따라서 '토스 승인만 오면 바로 판매 가능'으로 표현하지 않는다.

미디어 저장소는 여전히 기존 Supabase/local 드라이버다. Cloudflare R2 전환은 별도 복사·접근권한·URL 검증 단계가 필요하며, 이 Cloudflare 스케줄러는 스토리지 이전을 의미하지 않는다.
