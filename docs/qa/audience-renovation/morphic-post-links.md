# Morphic 사례 원문 연결

2026-10-12 · `codex/morphic-post-case-links`

기존 “Morphic에서 90년대 인터뷰 포맷 보기”가 일반 제작 가이드로 연결되고 있었다. 대표 요청에 따라 브랜드 랜딩에서는 인스타그램 실제 게시물과 TWINGS 사례 상세를 보여 준다. 제작 방식이 궁금한 방문자는 사례 상세의 보조 링크에서 YAGI가 만든 포맷을 확인할 수 있다.

## 확인한 자료

- 로그인된 `brand.twings.app`의 8월 한국 캠페인과 9월 한국·일본 캠페인. 읽기 전용으로 확인했으며 캠페인 데이터는 수정하지 않았다.
- Pitch의 `[D2] YAGI WORKSHOP_Introduction`, 발표 자료의 한국·일본 콘텐츠 예시. 현재 화면에서 링크를 확인했으며 소개서의 편집·공유 설정은 바꾸지 않았다.
- 대표가 지정한 [90s Korean street interview](https://morphic.com/en/workflows/019feecc-c7ec-77bd-bc3a-2ddc1f680105/90s-korean-street-interview). 실제 공개 페이지의 제목과 주소를 확인했다.
- 아래 여섯 게시물을 로그인된 Chrome에서 직접 열어 Morphic 캠페인 내용과 원문 페이지를 확인했다. 개별 크리에이터 이름·핸들·계약·연락처·성과 수치는 공개 문안에 추가하지 않았다.

## 문안 검토

Claude Code의 `claude-opus-4-6`을 도구 없이 호출해 브랜드 랜딩·고객 사례·관련 FAQ의 공개 문구를 검토했다. 비밀값·고객 기록·실제 프롬프트·얼굴 사진은 전달하지 않았다. 한국어 자연스러움과 구체성을 기준으로 다음을 반영했다.

- “확인 가능한 성과”를 “확인된 성과”로 줄였다.
- 8월 지표 주석의 중복된 고객명과 포맷 설명을 덜어냈다. 중복 조회와 전환율 미집계 안내는 유지한다.
- “한국과 일본에서도”를 “한국과 일본에서”로 바로잡았다.
- 제작 포맷의 주체를 YAGI로 명시한다.
- 실제 게시물 링크와 기존 제작 영상의 관계를 분명하게 안내한다.

Opus가 기존 제작 영상을 실제 게시된 Instagram 영상이라고 단정한 제안은 사실관계와 맞지 않아 반영하지 않았다. 영상 배열이 네 편으로 늘어난다는 의견도 잘못된 전제여서 제외했다. 제작 영상은 두 편 그대로이며 원문 링크만 네 개 추가한다. 전후 문구와 채점은 [문안 비교 CSV](morphic-copy-review.csv)에 기록한다.

## 검증

새 회귀 검사는 수정 전 실패를 확인한 뒤 구현했다. 두 언어의 랜딩은 Morphic 외부 링크가 없고, 사례 상세에는 대표가 지정한 제작 포맷만 연결된다. 한국·일본 원문 링크, 8월 지표 격리, 비공개 브랜드 공간으로 이동하지 않는 동작을 확인한다. 필수 전체 검사·빌드·익명 스윕·화면 검증·Director 리뷰·배포 결과는 PR 본문에 기록한다.

외부 Instagram 페이지는 플랫폼 정책에 따라 로그인 화면이 표시될 수 있다. TWINGS 안의 기존 영상 미리보기는 그대로 제공된다.
