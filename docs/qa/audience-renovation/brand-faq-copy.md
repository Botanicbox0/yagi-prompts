# 브랜드 FAQ 문안 수정 — 2026-10-08

## 변경과 승인 근거

대표 요청에 따라 브랜드 FAQ 답변 8개(`faq.a9`~`a16`)의 한국어와 영어를 다듬었다. 같은 사전을 사용하는 브랜드 페이지, 전체 FAQ, `FAQPage` 구조화 데이터가 함께 갱신된다.

영상 사용 권한은 캠페인 전 협의뿐 아니라 캠페인 이후 라이선스 구매도 가능하다는 대표의 설명을 반영했다. 사용할 채널·기간·유료 광고·재편집은 크리에이터와 협의한다. 가격이나 기본 권리 기간을 새로 정하지 않는다.

> 네. 캠페인 시작 전에 사용권을 함께 협의하거나, 캠페인이 끝난 뒤 원하는 영상의 라이선스를 따로 구매할 수 있습니다. 사용할 채널과 기간, 유료 광고·재편집 여부는 크리에이터와 협의해 정합니다.

## Opus 4.6 검토

실제 Claude CLI에 `--model claude-opus-4-6`을 지정했다. 공개 FAQ 문안만 전달하고 도구와 MCP 접근을 비활성화했다. 첫 검토는 한국어 재작성과 같은 사실의 영어 답변을 제안했다. 본인 얼굴 원칙과 기존 사례의 사실 관계를 맞춘 뒤 한국어 최종본 8개를 다시 검토받았다.

두 응답 모두 `is_error: false`이며 `modelUsage`는 `claude-opus-4-6`이다. 최종 판정은 `ship`, `required_changes: []`. 문안의 자연스러움과 명확성을 검토한 결과이며 법률 자문·독립적인 캠페인 성과 검증·화면 검증을 의미하지 않는다.
