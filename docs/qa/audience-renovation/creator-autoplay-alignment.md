# 크리에이터 랜딩 자동 재생과 템플릿 정렬 — 2026-10-08

대표가 첨부한 크리에이터 랜딩 화면을 기준으로 첫 화면 영상의 호버 의존을 없앴다. 한국어·영어 홈에서 화면에 들어온 예시 영상은 음소거로 반복 재생한다. 영상 멈추기·재생 버튼은 링크와 분리해 키보드로도 조작할 수 있다. 화면 밖이나 숨겨진 탭에서는 멈추고, 사용자가 직접 멈춘 영상은 스크롤이나 탭 전환으로 다시 재생하지 않는다.

동작 줄이기, 데이터 절약, 2G 연결에서는 포스터를 먼저 보여주고 버튼을 누르면 재생한다. 포스터는 첫 화면 이미지로 우선 로드하고 영상은 `preload="none"`으로 둔다. 카탈로그의 호버 미리보기는 유지한다.

템플릿 목록은 CSS 다단 배치 대신 행 단위 그리드로 표시한다. 카드의 미디어 비율은 기존 16:9이며 세로 원본도 자르지 않는다. 같은 행의 카드 높이를 맞추고 상세 보기 영역을 하단에 정렬한다. 긴 제목이 있는 카드 뒤로 단차가 누적되지 않으며, 보이는 순서와 키보드 순서가 일치한다. 용도 필터도 같은 목록에 적용한다.
