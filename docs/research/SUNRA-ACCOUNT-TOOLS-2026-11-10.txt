===== create_image
create_image: Create image

Generate images on a project with models such as FLUX, GPT Image, Nano Banana, Seedream, Midjourney, Ideogram, Krea and Grok Imagine (model ids from list_models). count is how many images, the same number as the web quantity control. Omit count for one task. The credit total is the price of one task times the number of tasks. A model that returns several images per task snaps count onto whole tasks, and the result says how many images that is. A count above the model limit is an error. Personal stages one hidden node per task. Team creates an Assets plan without a Canvas node or edit lease; specify an explicitly supported model, and read results with get_job. Both return the total credit cost. Pass auto_confirm=true to spend immediately. Otherwise call confirm_execution once, with any returned plan_id, to start every task from this request. Personal uses wait_for_nodes for the output URL. Team get_job returns COMPLETED with downloadable urls after publication; list_workspace_assets and the authenticated project_url locate the assets. Lands on the Project tab (asset list), not a timeline. Running generations are capped per plan, by type and in total. Personal: get_balance and estimate_cost show how many can start; wait for running nodes with wait_for_nodes before sending the rest. Team: get_balance reads Team/member quotas; get_job polls admitted task_ids. After a partial or unknown Team submission, reuse the original plan_id; do not create replacement plans automatically.

===== create_video
create_video: Create video

Generate videos on a project with models such as Kling, Veo, Seedance, FLUX, Wan, MiniMax, Grok Imagine and Happy Horse (model ids from list_models). count is how many videos, the same number as the web quantity control. Omit count for one video. The credit total is the price of one video times count. A count above the model limit is an error. One confirm_execution on any returned plan_id starts every video from this request. Pass auto_confirm=true to spend immediately. Lands on the Project tab, not a timeline. Choose the input with start_image, end_image, reference_images, reference_videos, reference_audios, or source_video. image_urls is the old compatibility field and is ignored when any of those is set. seedance-2.5 at 480p with a fixed duration is a preview unless draft is false. The preview price matches a standard 480p video. Pass draft_source_task_id (our preview task id) to make a separate 1080p final at the 1080p price. Or pass the task_id of a finished Pika H3 Flex 480p or 768p video as draft_source_task_id, with resolution 1080p, 2k or 4k, to upgrade that video; the charge is only the price difference per second of the source. A final or an upgrade is one video. Running generations are capped per plan, by type and in total. Personal: get_balance and estimate_cost show how many can start; wait for running nodes with wait_for_nodes before sending the rest. Team: get_balance reads Team/member quotas; get_job polls admitted task_ids. After a partial or unknown Team submission, reuse the original plan_id; do not create replacement plans automatically.

===== get_job
get_job: Get job

Look up one generation job by task_id. Own jobs only. Team generation jobs (Assets or original Canvas) are read-only: published READY outputs return COMPLETED with urls/out_* using the same download convention as Personal, plus workspace_status, asset metadata and project_url; no Canvas or lease is involved. Personal also writes completed results or failure status back to the job's canvas node. Personal and Team jobs have draftFinalize (eligible, reason, expiresAt, finalizedTaskId); only a finished seedance-2.5 preview, or a finished Pika H3 Flex 480p or 768p video (then upgrade gives its source resolution and seconds), can be eligible. That object never includes an upstream draft id. A failed job may have error_reason and error_hint, which say what was wrong with the input and how to fix it; follow error_hint before retrying.

Arguments (JSON schema):
{
  "type": "object",
  "required": [
    "task_id"
  ],
  "properties": {
    "task_id": {
      "type": "string",
      "description": "Returned by a create with auto_confirm, by confirm_execution, and by wait_for_nodes."
    }
  }
}

===== create_project
create_project: Create project

Create a project in this MCP connection's selected workspace. Team projects require workspace_id matching the selected workspace and a stable request_id reused on retries, so switching connections/selections cannot redirect a retry. Team generation availability is reported by capabilities as a feature hint, not authorization for every model or balance. For Team Assets generation use create_image/create_video/create_audio/create_model3d with explicit model, show estimated_credits and maximum_credits, then confirm_execution; no editor lease or Canvas is required. ===== get_model_schema
get_model_schema: Get model schema

Legal inputs for one catalog model (aspect ratios, durations, resolutions, reference image and video limits). Does not include prices. Reference image count follows max_ref_images, but some video routes take fewer (see create_video reference_images). max_ref_videos is the catalog cap for reference_videos. When present, reference_image_rules, reference_video_rules and reference_audio_rules are the file size, dimension, aspect ratio, length and format limits the model enforces on those inputs, duration_range is the accepted length and step for sound effects, and max_source_video_seconds caps a source video. Check inputs against them before creating; a file outside them makes the job fail.

Arguments (JSON schema):
{
  "type": "object",
  "required": [
    "model"
  ],
  "properties": {
    "model": {
      "type": "string",
      "description": "Catalog model id. A model omitted from list_models can still be passed here."
    }
  }
}
