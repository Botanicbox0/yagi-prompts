# 크리에이티브 가격·수익 문구 — 로컬 Gemma 추천 (2026-11-02)

대표 지시(2026-11-02): "크레딧을 올리면 사용자 소모가 늘고, 한 번 만들 때 내 몫은 이만큼"은 너무 구리다. 새로 만드는 화면 문구는 로컬 Gemma에 전체 맥락을 주고 추천받아 설계한다.

- 모델: `yagi-crm-gemma4:31b-q8_0`, `http://127.0.0.1:11434`(gpu-arbiter 경유), temperature 0.5~0.6, JSON 출력.
- 프롬프트: 서비스 정의, 가격·정산 사실(80%, 7일, 기본값 아래 불가, 회사 계정), 호칭("AI 크리에이티브", 일반 사용자 호칭 없음), 금지 패턴(소모·내 몫·배분·귀속, 기계적 병렬, 명령+약속, 대조 공식)을 모두 넣었다.
- 받은 뒤 사실과 어긋난 추천은 이유를 적어 다시 물었다(2차). 3차는 스튜디오 보조 문구와 관리자 문구다.
