# 얼굴 기준 사진 — Sonnet 4.6 문안 검토

2026-09-22 · Claude Code 2.1.223 · `--model claude-sonnet-4-6` 명시 호출. 검토만 요청하고 파일 수정 도구는 제공하지 않았다. 전체 한국어 사전과 얼굴 기능 영어 사전·컴포넌트를 전달했고, 응답의 모델 사용 기록에서 Sonnet 4.6 호출을 확인했다.

## 반영한 의견

| 항목 | 수정 | 이유 |
| --- | --- | --- |
| 첫 방문 잔여 횟수 | “무료로 2번 더” → “무료로 2번” | 처음부터 추가 혜택처럼 읽히는 표현 제거 |
| 생성 버튼 | “내 얼굴 만들기” → “기준 사진 만들기” | 만들어지는 대상을 명확히 안내 |
| 소개 | 완성된 사진을 확인·선택하면 다음 영상·이미지에 사용 | 업로드 사진과 생성 결과 구분 |
| 재생성 | “더 잘 맞는 결과를 얻을 수 있어요” → “더 잘 나올 수 있어요” | 번역투 축소 |
| 실패 | “무료 횟수는 줄어들지 않았어요” → “남은 횟수는 그대로예요” | 더 짧고 자연스러운 상태 설명 |
| 진행 중 버튼 | 긴 설명 대신 “처리 중…” | 모바일 버튼이 여러 줄로 늘어나는 문제 방지 |
| 소진 상태 | “무료로 0번 더” 대신 “무료 생성 2회 사용 완료” | 상태를 직접 설명 |
| 얼굴 확인 설명 | “기존 … 유지됩니다” 대신 사용 목적과 추가 확인 가능성 | 신규 사용자에게 불필요한 내부 변경 설명 제거 |

진행 중 버튼과 상태 문단의 문구는 분리했다. 자동 스크롤은 기기의 모션 감소 설정을 따른다.

## 유지한 결정

- 대표가 정한 업로드 문장과 예시 사진 4장은 그대로 유지.
- “내 얼굴처럼 나왔나요?” / “네, 이 얼굴로 사용할게요”는 질문에 답하는 사용자 확인 흐름에 맞으므로 유지. 모든 버튼을 명사형 행동 문구로 바꿔야 한다는 제안은 채택하지 않았다.
- 제목을 “기준 사진을 만듭니다.”로 바꾸는 제안은 기존 제품 어투보다 딱딱해 채택하지 않았다.
- “앱을 닫아도…”라는 단정 대신 웹·PWA 모두에 맞는 “화면을 나갔다가 돌아와도…”를 유지했다. 실제 기기별 종료·복귀는 별도 검증이다.
- 첫 생성 포함 무료 2회와 실패 미차감 숫자를 유지. 정책이 확정되어 있으므로 숫자를 감추지 않는다.
- 법무·환불정책·가격·모델·무료 횟수 정책은 수정하지 않았다.

Sonnet의 검토는 문안에 대한 의견이며 실제 기기 동작이나 얼굴 보존 품질의 검증을 대신하지 않는다.
