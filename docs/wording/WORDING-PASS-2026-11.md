# TWINGS 전 페이지 워딩 패스 — 2026-11 (Bundle G)

## 1. 목표와 범위

`AGENTS.md` §9(워딩 SOTA 패스)와 `docs/HANDOFF-2026-11-11-GEMINI.md` Bundle G 지시에 따라 공개 페이지, 개인 앱, 브랜드 워크스페이스·스튜디오(이미지·비디오·영상 합치기)·프로젝트 룸·저장 한도 안내, 관리자 콘솔 전 범위의 노출 문자열(사전 `7,268`키 · 한/영 `14,536`문자열 · `220`개 라우트)과 JSX 하드코딩 문자열을 점검·정비했다.

- **채점 3축 (1~5점)**: 명확성(한 번에 읽히는가) · 구체성(숫자·행동이 있는가) · 자연스러움(한국인이 실제로 쓰는 말인가).
- **재작성 원칙**: 한 문장 한 생각, 번역투·기계적 병렬·과장 형용사 제거, 내부 은어(`홀드`, `슬롯`, `반려`, `S1~S5`, `보관함`) 제거, CTA는 동사로 마무리, 설명서 말투 지양.
- **검증 아티팩트 동기화**: `docs/wording/reviews.json`(`330`키 직접 검토 반영), `inventory.csv`, `routes.csv`, `hardcoded-candidates.csv`, `proposals.md`, `summary.json` 전부 `npx tsx scripts/dump-wording.ts --check` 통과.

## 2. 건드리지 않은 하드라인 (변경 0건)

1. **약관·환불·개인정보 본문**: `lib/legal/documents.ts` 및 법무 페이지 문안.
2. **가격·정산 조건·대표 결정 대기 항목**: `reviews.json`의 `decision: "owner-decision"` 항목, 플랜 가격·수수료·환불 기간.
3. **외부 발송 메일·SNS 본문**: `email.*`, `notify.*` 등 실제 발송 문안.
4. **역할 호칭 및 브랜드 포지션**: `메이커 / Maker`, `크리에이터`, `개인 | 브랜드`, 승인 실적 숫자(**글로벌 AI 플랫폼 · 영상 9편 · 200만 뷰+ · 파생 오가닉 콘텐츠 300건+**).
5. **대표 확정 문장**: `"각 이미지 모델에 최적화 된 프롬프트가 생성됩니다."` 원문 그대로 보존.

## 6. 되돌리는 방법 (Rollback)

모든 변경은 `messages/*.ts` 사전과 4개 컴포넌트의 사전 바인딩으로만 구성되며 DB 스키마·API 계약 변경이 없다. 되돌리려면 해당 PR 커밋을 `git revert`한 뒤 `npx tsx scripts/dump-wording.ts`를 다시 실행하면 즉시 이전 문구로 복원된다.
